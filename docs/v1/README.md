# StayOps Claude Code 문서 패키지

이 패키지는 StayOps 호텔 운영 도메인 프로젝트의 기준 문서다.

## 포함 문서

1. `01_PRODUCT_DISCOVERY.md`
   - 문제 정의, 회사·시장 맥락, 공개 리서치, 제품 가설, 검증 계획, 합성 데이터 가정, MVP 범위
2. `02_TECHNICAL_DESIGN.md`
   - 기술 스택, 아키텍처, 도메인 모델, 상태 전이, readiness 계산, API, 테스트, 구현 순서
3. `03_CLAUDE_CODE_HARNESS.md`
   - Claude Code 작업 규칙, 구현 단계, 완료 조건, 테스트 시나리오, 첫 세션 프롬프트

## Claude Code에 전달하는 방법

1. 프로젝트 저장소 루트에 `docs/` 디렉터리를 만든다.
2. 세 개의 Markdown 문서를 `docs/`에 복사한다.
3. Claude Code에서 `03_CLAUDE_CODE_HARNESS.md`의 **첫 번째 Claude Code 프롬프트**를 실행한다.
4. 첫 단계에서는 코드 수정 없이 저장소 현황만 조사하게 한다.
5. 이후 Phase 단위로 진행하고, 각 단계의 테스트 결과를 확인한다.

## 중요한 전제

- 실제 호텔 운영자 인터뷰 및 실제 운영 데이터는 확보되지 않았다.
- 공개 연구와 제품 문서는 도메인 설계 참고 근거이지, 실제 운영사의 내부 운영을 설명하는 자료가 아니다.
- 초기 객실 수·인력 수·작업 시간은 합성 데이터 가정이다.
- 시뮬레이션 결과를 실제 호텔 운영 성과로 표현하지 않는다.
- 프로젝트는 초기 MVP이며, 미결정 사항은 ADR로 기록한다.
