## 이 디렉터리의 성격

v4.1은 v4 문서 7개를 다시 쓴 완성본이 아니라 **변경 제안 세트**다. 각 변경이 v4의 어느 문장을 어떻게 바꾸는지 변경 전/후로 기록한다.
승인된 항목만 v4.1 정식 문서 세트(01~07 갱신본)에 반영한다. 승인 전까지 `docs/README.md`의 현재 기준 버전은 v4로 유지한다.

| 라벨 | 의미 |
|---|---|
| `APPROVED` | 사용자가 승인함 |
