운영 테스트는 세 번 실행했습니다. 앞의 두 번에서 실패가 나왔고, 원인을 확인해 고친 뒤 깨끗한 데이터로 처음부터 다시 실행했습니다.

### 운영 테스트 후 오류 전수 점검

운영 테스트를 마친 뒤 서버 로그·개발 서버 로그·브라우저를 모두 다시 확인했습니다.

| # | 어디서 | 내용 | 원인 | 조치 |
|---|---|---|---|---|
| 3 | 백엔드 전체 테스트 | OpenAPI 계약 테스트 1건 실패 | API 설명 문구를 '데모 데이터'로 바꾸고 계약 스냅샷을 다시 만들지 않음(작업 누락) | 스냅샷 재생성. 계약 테스트가 의도대로 변경을 잡아냄 |
| 4 | API 로그 | `Response already committed … Broken pipe` 경고 | 운영 테스트가 화면을 빠르게 옮기면서 브라우저가 응답 도중 연결을 끊음. 서버 오류 아님 | 연결 끊김은 debug로만 기록하도록 변경 + 단위 테스트 |
| 5 | 개발 서버 로그 | `/guide`에서 `reading 'matchAll'` 오류 | 사용 설명서 데이터 구조를 바꾸는 도중(원본만 바뀌고 화면 코드는 아직)의 일시 상태를 개발 서버가 다시 그림 | 재현 확인: 4개 역할 × 라이트·다크로 모든 메뉴·객실 상세·설명서 5개 탭을 열어 **콘솔 오류·페이지 오류·HTTP 4xx/5xx 0건** |

이 밖에 운영 테스트를 준비하면서 데모 서비스를 직접 써 보고 고친 것(같은 날 사용자 확인 피드백): 준비 안 된 객실의 체크인 버튼이 눌리던 문제, 서버 영어 설명이 그대로 보이던 오류 안내, '준비 위험'·'판정 불가'처럼 뜻이 잘 와닿지 않는 표현. 모두 TC-R01·TC-D01·TC-U01에서 다시 확인했습니다.
